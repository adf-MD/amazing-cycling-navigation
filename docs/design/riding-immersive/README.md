# Immersive Riding design references

These mock-ups illustrate the intended visual hierarchy and interaction model for the proposed immersive Riding redesign, including:

- the compact Pause/title/End header;
- large Map and Profile views;
- prominent, touch-friendly screen switching;
- climb presentation;
- inline End-ride confirmation;
- the paused Ride launcher.

They are design references, not pixel-perfect specifications or screenshots of implemented behaviour. `CLAUDE.md` and the approved implementation prompt for each slice remain authoritative. If a mock-up conflicts with a written requirement, the written requirement takes precedence.

Exact dimensions, colours, sample values, icons and incidental control positions may change to satisfy the existing design system, accessibility requirements and real-device constraints. In particular, the agreed map layout places zoom controls at the top left and the existing camera controls at the top right.

These images do not constitute automated or real-device verification.
